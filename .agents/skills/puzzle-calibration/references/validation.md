# 误差与复标

## 验证方法

使用未参与拟合的点覆盖纸面中心与四周，比较预测位置与实际工具位置，报告毫米误差的均值、最大值和方向。像素重投影误差不能替代末端定位误差。

分别测静态定位、正反向到位和旋转后到位。正反差异提示回程间隙；随视野位置增长的误差可能来自畸变或平面映射；旋转相关偏差可能来自工具偏心。

## 复标条件

相机、镜头焦距、分辨率、纸面、机械原点或工具安装改变后重新核验，必要时重标。S3附带的标定参数只描述作者设备，不应移植。

## 记录字段建议

设备标识、分辨率、单位、坐标方向、标定日期、点对、拟合残差、独立验证残差。上述为资料建议，本轮不定义文件格式。
