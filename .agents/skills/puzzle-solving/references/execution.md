# 布局与搬运顺序

## 从解到动作

布局求解给出每片目标位姿；搬运规划还需选择抓取点、旋转中心、接近路径和放置顺序。几何解存在不表示吸头能无碰撞放到目标。

比较候选布局的行程、旋转量和工具可达性。先安排会被后续碎片遮挡的目标，移动过程抬到经验证的高度；不得让未移动碎片进入工具扫掠区。

## 扑克牌候选

在几何可行解中检查纹理连续性。不能凭花色识别替代切边配对，也不能仅用矩形外框判定花纹正确。

## 验证场景

相同面积不同形状、对称片、多几何解、纹理冲突、近似边长以及无解输入。求解超时应返回未完成状态，不能输出最后一个未经验证的候选。
