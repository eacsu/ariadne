# 通信与到位

## GRBL v1.1（S6、S8）

发送一行命令后处理 ok 或 error；ok表示命令被接受处理或排入执行，不证明机械已经到位。抓取或放置前结合实时状态与目标位置判断动作完成。

?查询状态，状态报告使用尖括号包围，并可能夹在普通命令回应之间。解析器必须区分状态、确认、错误、报警和重启消息；不能把下一行任意文本当作确认。

## 控制建议

首次实现可使用逐行应答，之后再考虑流控优化。设置超时，发生重启或报警时清除本地待执行假设并重新确认坐标状态。不要盲目重发可能已经执行的移动或抓取。

使用明确单位和绝对/相对模式，并区分MPos与工作坐标。暂停、复位与硬件急停的效果不同，必须实测设备行为；暂停不保证断电或停止吸取。
