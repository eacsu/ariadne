# 平台与运动

## 机构选择

XY龙门和CoreXY都可承担平面搬运，需另外解决Z升降与工具旋转。CoreXY电机与纸面轴不是一一对应；运动学映射交由正确配置的控制器处理，避免上下位机重复转换。

步数每毫米由电机整步、细分与传动比例共同决定。先低速测正向，再测已知距离，最后测往返误差。皮带张力、松动和负载变化可能导致机械误差，不能全部靠软件比例补偿。

## 调试顺序建议

确认电气与方向 → 回零 → 行程与限位 → 空载移动 → 持片运动。速度和加速度逐步提高，观察丢步、振动和吸取稳定性。所有数值依实际机构测定。

GRBL参数参照S7；FluidNC为另一候选（S9），不可直接套用所有配置。
