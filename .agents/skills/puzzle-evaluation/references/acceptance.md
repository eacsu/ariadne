# 验收矩阵

## 测试组织

依据题面评分文档逐项测试，不将建议的工程精度替代官方2 cm判定。每种任务覆盖随机位置与角度、正常室内照明变化和至少多次独立启动。

|场景|记录|失败判据|
|---|---|---|
|自备四片|搬运数、完成布局、总时间|未全部搬走、错位、重叠、超时|
|未知白片|形状、目标、对应顶点间距|无解、拼错、间距越限|
|扑克牌|边界和纹理照片、总时间|几何正确但纹理错误|
|异常恢复|触发原因、状态、恢复步骤|误报成功或未经确认继续运动|

计时包含采图、计算、运动与完成指示。报告成功率的分母包含失败轮次；保存原始记录，不仅展示最快一轮。

## 联调层次

先离线检查视觉与求解，再空载验证动作，最后持片整机测试。实际操作前验证限位和急停。
