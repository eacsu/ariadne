# 报告与实验记录

## 报告结构建议

摘要、任务分析、方案比较、理论计算、硬件电路、软件流程、测试方法与结果、问题分析、参考资料。各节围绕评分项展开，完整评分分配见题目技能。

理论部分解释轮廓识别、坐标映射和拼接约束；电路部分包含实际电源与驱动；程序部分给出实际实现流程，而不是尚未实现的设想。

## 单次记录模板

- 日期、设备与软件版本：
- 任务类别、碎片条件、起始照片：
- 标定版本、室内照明条件：
- 各阶段时间及总时间：
- 最大对应顶点间距、重叠检查、花纹检查：
- 成功或失败、失败阶段与原因：
- 结果照片和日志位置：

模板字段需要实测填写。没有实测就明确写未验证，不用他人项目数据充当自己的结果。
