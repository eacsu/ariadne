# 任务生命周期

## 推荐状态

待机 → 启动采图 → 识别 → 求解 → 执行 → 复核 → 完成指示。任一步失败进入故障状态，保留原因；只有完成条件满足后才能发成功指示。

比赛计时从一键启动和撤去遮挡开始，不能通过预先观察碎片来缩短计时。启动前可完成设备准备和合法标定，但不能预知本次摆放。

## 模块边界建议

视觉提供观测和质量，求解提供目标布局，规划提供动作序列，控制器反馈真实状态。上层不能把命令发出当作动作完成。

## 故障案例

相机掉线、碎片数量不符、无解、吸取失败、运动报警或通信超时均应可定位。恢复前重新确认物体和机器状态；不能重放旧动作序列。保留各阶段耗时与失败原因用于复盘。
