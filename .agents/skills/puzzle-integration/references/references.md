# 参考项目与技术边界

## 已找到的作者方案（S3）

作者公开了Raspberry Pi 5视觉上位机、GRBL三轴平台、MSPM0G3507辅助控制及旋转舵机、电磁铁组合，另有相机和坐标标定程序。仓库自述江苏省一等奖，本项目未独立核实获奖记录或复现性能。

值得阅读的是标定链、运动与吸取分工、异常处理以及硬件连接说明。模型、照片与设备标定文件不是通用配置，不能直接搬用。

## 本项目默认边界

尚未选择计算平台、相机、控制器和通讯链路。GRBL与FluidNC作为候选比较；视觉模型也非必需。评估标准为题目覆盖、调试成本、设备能力和可验证性。

复用代码前阅读上游许可证及第三方声明；当前知识库只整理理解，不镜像仓库。
